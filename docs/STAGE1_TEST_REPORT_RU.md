## Как повторить доступные проверки

В папке исходников с установленными Luau/Rojo/Python:

```sh
python tools/check.py
```

Если исполняемые файлы находятся вне PATH:

```sh
python tools/check.py --bin-dir /путь/к/luau-и-rojo
```

Этот скрипт компилирует Luau, анализирует чистые модули, исполняет 36 проверок, собирает временный place и проверяет его структуру. Временная сборка удаляется после проверки.

В Play Mode, в серверной Command Bar Studio:

```lua
require(game.ServerStorage.Stage1Tests).Run()
```

Модуль проверяет реальные hitbox и препятствия, фронт/тыл блока, урон, пробитие защиты, повторные запросы, одно попадание за активное окно и отмену отложенного попадания после удаления атакующего. Тестовые объекты удаляются и при успехе, и при ошибке. После него выполните ручные сценарии для одного и двух игроков из `README_RU.md`.

## Ограничения сборки

Этап 1, ПК с клавиатурой и мышью; оригинальные процедурные R15-модели и анимации. Мана расходуется на Q для проверки системы ресурсов. Уровень фиксирован на 1, сохранения нет. Магия, пробуждения, оружие, воздушные комбинации и spell clash относятся к следующим этапам и в этом проекте ещё не реализованы.
