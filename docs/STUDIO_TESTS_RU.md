# Проверка в Roblox Studio

Эти сценарии подготовлены, но **не запускались в облачной среде**. Компиляция Luau и сборка Rojo не заменяют выполнение Roblox API, физики, локального интерфейса и репликации. Испытывайте отдельную копию place до публикации.

## Серверные интеграционные тесты

1. Откройте `BlackClover_Magic.rbxlx`, запустите Play/F5. Откройте Output и Command Bar.
2. Переключитесь на серверный контекст. Дождитесь сообщения `[Black Clover] Core + 7 magic classes / 44 spells initialized`.
3. Выполните по очереди:

```lua
require(game.ServerStorage.Stage1Tests).Run()
```

```lua
require(game.ServerStorage.MagicSystemTests).Run()
```

Ожидаются сообщения `PASS` без красных ошибок в Output. Тест магии занимает около минуты: создаёт собственную площадку и актёров на высоте 180 studs, проверяет выбор классов, сохранение маны/CD, расход четырёх форм, G/нулевую ману, щит, разрушение стены, попадание снаряда, отражение, выпуск всех 44 заклинаний и отмену отложенного дождя. В конце убирает созданные объекты. Повторный параллельный запуск запрещён.

`Stage1Tests` проверяет исходные M1/блок/хитбоксы/стены/спам атак и отмену отложенного попадания. `MagicSystemTests` проверяет серверные маршруты и основные механики; прохождение этого теста само по себе не подтверждает каждое визуальное состояние и все сценарии PvP.

Если тест завершился ошибкой, сохраните **полный текст первой ошибки и stack trace**, название способности, выбранный класс, остаток маны и действия перед ошибкой. Не считайте сборку проверенной по одному сообщению о запуске Bootstrap.

## Одиночный ручной проход

| Сценарий | Что должно произойти |
|---|---|
| M → каждый из семи классов | Один гримуар соответствующего цвета/символа; четыре названия способностей в HUD |
| Антимагия → другой класс → Антимагия | Ровно один меч; M1 использует оружейные движения и серверный урон |
| Z/X/C/V каждой базовой магии | Мана/CD, подготовка и выпуск; урон или работающая защита/контроль/перемещение |
| Земля X | Стена поднимается, физически блокирует; HP уменьшаются от чужих атак; разрушение/истечение убирает коллизию |
| Земля V | Голем ищет цель, ходит, наносит обычные и ударные атаки; получает урон; второе V отзывает его |
| Ветер C | Ястреб доворачивает к ближайшему доступному противнику возле точки прицела |
| Лёд V и повторные попадания | Зона, периодические удары, стеки замедления и короткая заморозка |
| Кости X / усиленные X,C,V | Падающая ловушка, ограниченное обездвиживание, захват/удар рукой и атаки конструкций в зоне |
| Звёзды X в стену / за край | Персонаж не оказывается внутри стены; нет свободного места — возврат маны/CD |
| G у четырёх поддержанных классов | Последовательность 2,4 с, броня/крылья следуют R15; новый Z/X/C/V |
| G повторно и при нуле маны | Старая панель способностей, исчезновение временной экипировки; меч Антимагии остаётся |
| R в пробуждении Ветра/Антимагии | До 4 с управляемого полёта, затем отключение; чат/потеря фокуса прекращают передачу движения |
| Магический рывок из полёта | Один управляющий mover; полёт прекращается, рывок останавливается у препятствий |
| Смерть во время каста / смена класса | Нет старых снарядов, зон, голема, дубликатов книг/оружия после возрождения |
| Открыть M, чат или переключить окно при удержании M1/F | Удерживаемые боевые команды сбрасываются |

У источника E восстанавливаются параметры. Во время проверки точного расхода не применяйте способности и не используйте источник: за 10 секунд должно уйти 10/50/70/70 маны (Вода/Кости/Ветер/Антимагия). Отсчитывайте интервал по серверному времени, а не целочисленному округлению HUD. Регенерация при включённой форме не должна компенсировать расход.

## Два клиента

В Studio запустите **Server & Clients / Local Server** с двумя игроками. Не используйте два последовательных одиночных сеанса как замену этому тесту.

1. Встаньте друг напротив друга. Одновременно выпустите сопоставимые снаряды. Проверьте уничтожение/ослабление, общий эффект столкновения и отсутствие урона от уже уничтоженного снаряда.
2. Столкните более сильное усиленное заклинание с обычным. Повторите с Антимагией, льдом против воды и снарядом в торнадо. Сильная обычная магия должна пробивать слабую антимагию.
3. Поставьте земляную стену между игроками: M1/прямой снаряд должны остановиться у стены. Проверьте HP/разрушение и отсутствие столкновения снарядов сквозь стену. Наземные области и атаки сверху проверяйте отдельно.
4. Антимагия C: попадание спереди в окно парирования отражается; сзади и после окна — наносит урон. Сильнейшая атака ослабляется, но не полностью поглощается. Отражение не создаёт бесконечного обмена одним снарядом.
5. Включите G на обоих клиентах. Оба должны видеть книги, форму, крылья, оружие и анимации другого игрока. Подключите второго клиента к уже активной форме и повторите выключение/смерть/смену класса.
6. Нанесите подавление «Концом магии»: G отключается, новый каст недоступен 5 с, затем снова разрешён. M1 и обычное передвижение продолжают работать с учётом оглушения.
7. Повторите 10–20 циклов класса/G/каста/смерти. В клиентском Workspace проверьте `LocalMagicEquipment` и `LocalMagicVFX`, на сервере `MagicWorld`: не должно оставаться экипировки старых персонажей или бесконечно расти число сущностей.

Во время совместных крупных способностей следите за MicroProfiler, частотой кадров, сетевым трафиком и количеством экземпляров. 850 декоративных деталей — ограничение создания, а не подтверждённый результат измерения производительности. Под нагрузкой VFX могут упрощаться или пропускаться; это не должно менять серверный урон.
