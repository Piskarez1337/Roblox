# Black Clover RPG — этап 1, версия 0.1.0

Создан отдельный проект Roblox Studio с первым этапом: R15, передвижение, рукопашный бой, здоровье, мана и HUD. Это сборка для проверки в Play Mode. Она не содержит семь магий и пробуждения из последующих этапов.

## Открыть и запустить

1. Сохраните `BlackClover_Stage1.rbxlx` на свой компьютер. Если скачали полный архив, сначала распакуйте его.
2. Запустите актуальный **Roblox Studio** и войдите в свою учётную запись.
3. Нажмите **Ctrl+O** / **File → Open from File…** и выберите `BlackClover_Stage1.rbxlx`. Это готовый place, его не нужно вставлять как модель в Baseplate.
4. Откройте панели **Explorer**, **Properties** и **Output** через меню **View** либо соответствующие кнопки Studio.
5. Нажмите **Play / F5**. Используйте именно Play с персонажем, а не Run без игрока.
6. В Output должно появиться `[Black Clover] Stage 1 started. Server combat, mana and movement active.`
7. Проверьте персонажа, HUD и площадку по сценарию ниже. Чтобы закончить тест, нажмите **Stop**.
8. Сохраните свою копию через **File → Save to File As…**. Публикация в Roblox для локального Play Mode не нужна.

Rojo, плагины, включение HTTP, DataStore API и ручная вставка кода для запуска готового `.rbxlx` не нужны. R15 уже задан в собственном `StarterCharacter`; внешние аватары и их аксессуары не загружаются.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Передвижение |
| Shift, удерживать | Спринт |
| Space | Обычный прыжок |
| ЛКМ | Удар; удержание выполняет последовательность из четырёх ударов |
| F, удерживать | Блок спереди; запас защиты ограничен |
| Q | Наземный рывок по направлению движения; без движения — вперёд |
| E у источника | Восстановить здоровье, ману и защиту |

Основное управление рассчитано на клавиатуру и мышь. При атаке поверните персонажа к цели движением WASD. Смена ориентации одной камерой не разворачивает стоящего персонажа. Shift Lock отключён, поскольку Shift используется для спринта. Отдельные мобильные и геймпадные схемы пока не реализованы.

Z/X/C/V/G в этапе 1 не назначены. Воздушные комбо, оружие и магия не имитируются неработающими кнопками.

## Что включено

- Собственный R15-персонаж с 15 Motor6D, оригинальной геометрией и без внешних MeshId.
- Процедурные анимации покоя, ходьбы, спринта, торможения, прыжка, блока, рывка и четырёх разных ударов. Руки, корпус и ноги двигаются; анимации отображаются у всех клиентов по состоянию сервера.
- Четыре рукопашных удара: 10 / 11 / 14 / 20 урона. Четвёртый отбрасывает. Комбо сбрасывается после паузы 1,05 с.
- Серверные активные окна ударов, пространственные проверки, проверка дистанции и прямой видимости. Одна цель получает урон только один раз за удар, независимо от числа частей тела и повторных выборок hitbox.
- Фронтальный блок снижает урон на 80%. Защита расходуется, полная серия из четырёх ударов пробивает её. При пробитии — полный урон завершающего попадания и оглушение на 1,1 с. Удар сзади обходит блок.
- HP 120, мана 100. Q расходует 8 маны, перезарядка — 1,15 с. Вне расходования мана восстанавливается со скоростью 7/с после паузы 0,75 с. HP восстанавливается на 4/с после 7 с вне боя.
- Серверный расчёт ресурсов по `dt`. Плавное отображение HP, маны, защиты, серии ударов и перезарядки рывка.
- Ограничение запросов RemoteEvent, проверки аргументов, здоровья, оглушения и восстановления между действиями. Клиент не передаёт урон, номер удара, целевую модель или значение маны.
- Наземный рывок с серверным LinearVelocity и Blockcast перед препятствиями. Базовая проверка необычного горизонтального перемещения игрока. Это не полноценная защита от всех способов вмешательства в физику Roblox.
- Каменная арена с круговыми инкрустациями, колоннами, воротами, фонарями, деревьями и дальними скалами. Геометрия находится в файле place до запуска игры.
- Два неподвижных манекена с 300 HP; два R15-часовых с 110 HP, которые обнаруживают игрока, подходят, атакуют и возвращаются на позицию. После смерти они появляются снова через 4 с.
- Источник восстановления справа от точки появления. Подтверждение дистанции и перезарядки взаимодействия выполняет сервер.
- Локальные Trail, частицы попадания, числа урона, короткий световой импульс и небольшая тряска камеры. Временные VFX удаляются, количество ограничено.
- Короткие звуки из встроенного набора Roblox. Это временное звуковое оформление первого этапа, а не финальный набор аниме-звуков. Числовых выдуманных Asset ID нет.
- Очистка состояния при смерти, удалении персонажа и выходе игрока; сброс удерживаемых клавиш при потере фокуса или вводе в чат.

## Проверка в Play Mode — один игрок

1. После появления дождитесь окончания двухсекундной защиты спавна. Убедитесь, что HUD показывает 120 HP / 100 маны и собственный персонаж имеет R15-части.
2. Пройдите, побегайте с Shift, резко остановитесь и подпрыгните. Должны меняться движения рук и ног; при спринте появляются след и небольшой акцент поля зрения.
3. Стоя на земле, нажмите Q. Мана уменьшится на 8 и восстановится после задержки. Повторное Q до окончания перезарядки не выполняет второй рывок и не списывает ману. В воздухе Q пока не действует.
4. Подойдите лицом к одному из манекенов на расстояние около 3–4 studs. Четыре удара должны снять суммарно 55 HP, если все попали и между ними не было паузы для восстановления цели. Через 3 с без урона манекен начинает лечиться.
5. Отойдите за пределы 7,2 studs и атакуйте: урон не должен проходить. Проверьте атаку спиной к цели: попадания не должно быть.
6. Подойдите к часовому у дальних ворот. Он должен приблизиться и атаковать. Удерживайте F, стоя к нему лицом: здоровье теряется медленнее, защита падает. После пробития блока дождитесь восстановления. Сравните с атакой в спину.
7. Победите часового и дождитесь его нового появления через 4 с. Либо дайте ему победить вас: после возрождения должны снова работать HUD, управление, блок и атаки.
8. У источника справа от спавна удерживайте E. HP, мана и защита должны восстановиться. Удалённое взаимодействие вне радиуса не допускается сервером.
9. Проверьте рывок в колонну: персонаж должен остановиться у препятствия. Повороты и атаки под задержкой сети требуют отдельной настройки после реального теста.
10. В течение 2–3 минут повторяйте атаки и рывки. После прекращения атак временные `Workspace.LocalVFX` на клиенте должны удаляться. Постоянные Trail остаются привязаны к живым моделям.

## Проверка двух игроков

1. Остановите одиночный Play.
2. В **Test → Server & Clients / Local Server** выберите **2 Players** и запустите тест. Названия кнопок зависят от языка и версии интерфейса Studio.
3. Дождитесь загрузки обоих клиентов и окончания защиты спавна. Подведите персонажей друг к другу.
4. Атакуйте одним игроком другого. На обоих клиентах должны быть видны анимация и попадание, а здоровье должно измениться одинаково.
5. Второй игрок удерживает F лицом к первому: сравните уменьшенный урон с ударом сзади и проверьте пробитие защиты серией.
6. Проверьте, что мана и Q-перезарядка одного игрока не меняют ресурсы другого.
7. Возродите одного игрока через меню Roblox; у другого должны сохраниться управление и собственные значения HUD. Закройте один клиент и продолжите играть на втором.

PvP в тренировочной сборке включён. Команд, фракций и сохранения прогресса пока нет.

## Автоматические проверки внутри Studio

Модуль `ServerStorage.Stage1Tests` включён в place и сам по себе не запускается.

1. Нажмите Play.
2. Переключитесь на серверную сторону теста (**Server**, не **Client**).
3. Откройте **Command Bar** в меню View.
4. Выполните:

```lua
require(game.ServerStorage.Stage1Tests).Run()
```

Тест создаёт временных R15-актёров высоко над ареной и проверяет реальные Overlap/Raycast, дистанцию, препятствие, урон, фронтальный и задний блок, пробитие, ограничение повторных атак, одно попадание за активное окно и отмену отложенного удара после удаления атакующего. В конце удаляет созданные объекты. Успех выводится строкой `[Black Clover] PASS: ... Studio integration assertions`.

Этот тест **не запускался в облачной среде**, поскольку там нет движка Roblox Studio. Его наличие не заменяет ручную проверку ввода, камеры, анимаций и двух клиентов.

## Где находятся системы

| Путь в Explorer | Содержимое |
|---|---|
| `ReplicatedStorage/BlackClover/Shared` | Config, чистые Rules, PoseLibrary |
| `ReplicatedStorage/BlackClover/Remotes` | Action: запросы; FX: подтверждённые эффекты |
| `ServerScriptService/BlackCloverServer` | Bootstrap, Registry, CombatSystem, MovementSystem, Hitbox, EnemyAI |
| `StarterPlayer/StarterPlayerScripts/BlackCloverClient` | Bootstrap, AnimationController, VFXController, HUDController |
| `StarterPlayer/StarterCharacter` | Собственная R15-модель игрока |
| `StarterPlayer/StarterCharacterScripts` | Animate и Health, отключающие стандартные системы, чтобы они не дублировали наши |
| `ServerStorage/Actors` | Шаблоны манекена и часового |
| `ServerStorage/Stage1Tests` | Ручной запуск интеграционных проверок |
| `Workspace/TrainingGround` | Готовая сцена и источник восстановления |

`Animate` и `Health` содержат только пояснение намеренно: наличие этих имён предотвращает автоматическое добавление стандартной анимации и регенерации. Их функциональность реализована в `AnimationController` и `Registry`.

Для изменения баланса откройте `ReplicatedStorage/BlackClover/Shared/Config`. Здесь настраиваются скорость, прыжок, рывок, мана, лечение, окна комбо, урон, блок и AI. Уровень пока равен 1; функция максимальной маны учитывает уровень, но получение опыта и повышение уровня ещё не реализованы.

## Исходники и повторная сборка

Архив включает готовый place и инструкции в папке `BlackClover_Stage1/`, а исходники, модели `.rbxmx`, конфигурацию Rojo, генератор оригинальной геометрии и проверки — в её подпапке `source/`. Проект создан с **Rojo 7.7.1** и **Luau 0.745**.

Для обычной игры этот раздел не нужен. Для разработки установите Python 3, указанные инструменты Rojo/Luau, добавьте их в PATH и выполните из папки проекта:

```sh
python tools/build_assets.py
rojo build default.project.json --output BlackClover_Stage1.rbxlx
luau tests/rules.spec.luau
luau-analyze src/shared/Config.luau src/shared/Rules.luau tests/rules.spec.luau
python tools/verify_place.py BlackClover_Stage1.rbxlx
```

Все доступные офлайн-проверки одной командой: `python tools/check.py`. Для обновления готового place, ZIP и контрольных сумм в `dist/` выполните `python tools/package.py`. Эти команды не пересоздают модели в `assets/`.

`build_assets.py` пересоздаёт четыре файла в `assets/`. Если вы уже меняли модели вручную, сначала сохраните их копии; для сборки существующих моделей первую команду пропустите. Для синхронизации Studio с исходниками можно использовать официальный плагин Rojo и `rojo serve`; для открытия готового place это не требуется.

## Границы этого этапа

Созданы и собраны компоненты этапа 1. Не реализованы: семь магий, 28 базовых заклинаний, 16 усиленных заклинаний, гримуары, меч антимагии, броня и крылья, пробуждения с расходом маны, spell clash, парирование, воздушные комбо, пассивные эффекты и прокачка с сохранением. Эти системы не объявлены готовыми и не подменены заглушками.

Изображений Noelle / Wind / Bone / Anti magic / Grimoare в полученном вложении не было. Для последующих этапов потребуется сами изображения и, при необходимости, внешние качественные модели, анимации и разрешённые аудио. Текущая геометрия создана специально для тренировочной основы, без заявлений о совпадении с отсутствующими референсами.

Фактически выполненные проверки перечислены в `TEST_REPORT_RU.md`.
